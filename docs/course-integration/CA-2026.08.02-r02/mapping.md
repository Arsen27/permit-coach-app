# Package → app field mapping (CA-2026.08.02-r02)

The app has no content database: course content is bundled JSON under
`src/data/course/<courseId>/`, generated by `npm run course:import`
(`scripts/import-course.ts`). Supabase stores progress only and references
content ids as opaque `text` keys (≤ 64 chars), so every package id/UUID is
preserved verbatim. TypeScript shapes live in `src/data/course/types.ts`.

## Course version — `course.json` + `manifest.json` → `courseVersion.json` (`CourseVersion`)

| Package field | App field | Notes |
| --- | --- | --- |
| `course.uuid` / `manifest.id` | `uuid` | Verified identical during validation |
| `course.courseId` | `courseId` | Also the output directory name |
| `course.jurisdiction`, `state`, `title`, `language`, `targetLicense` | same names | Verbatim |
| `course.versionLabel`, `releaseDate`, `dailyRevision` (2), `stateSequence` (2) | same names | Verbatim, cross-checked against `manifest.json` |
| `course.status` | `status` | Stays `ready_for_review` |
| `manifest.publishedAt` | `publishedAt` | Stays `null` |
| `course.sourceCheckedAt`, `rulesEffectiveThrough` (null), `legalFreshnessStatus` | same names | Preserved as-is; source-check date is not an effective-through guarantee |
| `manifest.contentHash` | `contentHash` | Immutable snapshot identity |
| `course.moduleCount` … `totalQuestionCount` | same names | Validated against actual content before emit |
| `course.modules[].moduleId` (ordered) | `moduleIds` | Order source of truth for modules |

## Module — `modules/*.json` → `modules.json[]` (`CourseModule`)

| Package field | App field | Notes |
| --- | --- | --- |
| `moduleId`, `uuid`, `sequence`, `title`, `rationale` | same names | Verbatim; `sequence` validated as 1…13 in index order |
| `lessons[]` | `lessons` | Order preserved as stored |
| `moduleTest` | `moduleTest` | See below |

## Lesson — `modules/*.json` `lessons[]` → `CourseLesson`

| Package field | App field | Notes |
| --- | --- | --- |
| `lessonId`, `uuid`, `moduleId`, `title`, `estimatedMinutes`, `learningObjective`, `language` | same names | Verbatim |
| — | `sequence` | Derived: 1-based position in the module file (order preserved) |
| `content.introduction`, `summary`, `conditionNote`, `exceptionNote`, `numbersNote`, `importantConditions`, `exceptions`, `coachingNotes` | same names under `content` | Verbatim |
| `content.plainEnglishExplanation[].{ruleType, explanation}` | same | `ruleId` stripped (audit layer); `ruleType` kept so `universal-concept` guidance is never framed as state law |
| `content.practicalDrivingSituation.{scenario, recommendedResponse}` | same | Verbatim |
| `content.numbersAndLimits[].{label, value, source}` | same | `ruleId` stripped; human-readable `source` citation kept so displayed values retain attribution |
| `questions[]` (2 nested copies) | `questionIds` (2 ids) | Membership + order only; entities come from `questions.json` |

## Module test — `moduleTest` → `CourseModuleTest`

| Package field | App field | Notes |
| --- | --- | --- |
| `moduleTestId`, `uuid`, `moduleId`, `title` | same names | Verbatim |
| `questions[]` (nested copies) | `questionIds` | Membership + order only (≥ 6 per test) |

## Question — `questions.json` (canonical) → `questions.json[]` (`CourseQuestion`)

| Package field | App field | Notes |
| --- | --- | --- |
| `questionId`, `uuid`, `kind`, `scenario`, `question`, `correctAnswerId`, `explanation`, `difficulty` | same names | Verbatim; nested lesson/test copies were verified byte-identical to the bank before import |
| `choices[].{id, text}` | same | Ordered, exactly 4, one correct |
| `whyDistractorsAreWrong[].{choiceId, explanation}` | same | Coverage of all 3 distractors validated |

## Quiz-engine adapter — `src/data/course/adapters.ts`

`CourseQuestion` → existing `QuizQuestion` (`@/data/curriculum`): `questionId → id`,
`scenario + "\n\n" + question → prompt`, `choices → options`,
`correctAnswerId → correctId`, `explanation → explanation`. No image fields are
set — the package ships visual briefs, not finished assets, so lessons and
questions render without images until app-owned art exists.
